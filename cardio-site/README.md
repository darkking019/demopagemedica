# Dra. Mariana Silva | Cardiologia

Site institucional moderno e responsivo para a Dra. Mariana Silva, cardiologista em São Paulo.

## Estrutura do Projeto
dra-mariana-cardiologia/
├── index.html
├── assets/
│   ├── css/
│   │   └── styles.css
│   ├── js/
│   │   └── main.js
│   └── images/         
└── README.md
text## Como rodar

1. Baixe o projeto.
2. Abra o arquivo `index.html` diretamente no navegador (não precisa de servidor).
3. Tudo funciona com Tailwind via CDN (sem build).

## Tecnologias

- HTML5 semântico
- Tailwind CSS (via CDN)
- CSS customizado com glassmorphism e animações
- JavaScript vanilla (mobile menu, animações de scroll, formulário demo)
